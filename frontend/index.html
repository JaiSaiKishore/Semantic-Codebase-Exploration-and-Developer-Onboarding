hub Component Coupling & Stability Matrix Ca (Fan-in) • Ce (Fan-out) • Instability (I)
info
Understanding Robert C. Martin's Package Coupling Metrics:
• Afferent Coupling (Ca): Inbound dependencies — how many other modules depend on this component. High Ca means high responsibility (harder to change without breaking callers).
• Efferent Coupling (Ce): Outbound dependencies — how many external modules this component calls. High Ce means high sensitivity to external changes.
• Instability Index (I = Ce / (Ca + Ce)): Ranges from 0.0 (Maximally Stable) for core business entities to 1.0 (Maximally Volatile/Flexible) for entry controllers.
